# 把课题组网站挂到教师个人主页上

> 目标站点：<https://teacher.yzu.edu.cn/PW/zh_CN/index/497143/list/index.htm>
> 本文所有后台路径，均依据《教师个人主页服务平台——教师端操作说明书》与后台截图核对。

---

## 0. 先说清楚一件事

教师个人主页平台（`teacher.yzu.edu.cn/PW`）是**内容管理系统**，不是网站托管空间：

- 每位教师的初始容量 **1 GB**，只能存文章、图片、附件；
- 后台只有「栏目管理 / 内容管理 / 模板管理」，不能上传 `.html/.js/.css` 去运行；
- 因此**这个课题组网站无法直接放进主页系统里跑**。

所以真正要做的是两件事，顺序不能倒：

1. **先给网站一个公网 HTTPS 地址**（第 1 节）；
2. **再在主页里加一个入口或嵌入框**（第 2、3 节），指向那个地址。

如果暂时没有地址，只有第 4 节的「内容搬进主页」可以立刻做。

---

## 1. 第一步：给网站找一个公网地址

三个硬性要求：**HTTPS**、**国内能正常打开**、**支持上传多个文件（不是单文件）**。

个人建议按这个优先级选：

| 方案 | 说明 | 成本 | 备注 |
| --- | --- | --- | --- |
| **A. 学校 / 学院 Web 空间** | 向信息化处或学院申请一个 `*.yzu.edu.cn` 下的目录或虚拟主机 | 免费，需申请 | **最推荐**：域名同源、无备案问题、校内外访问都稳、长期可用 |
| **B. 腾讯云 EdgeOne Pages / 阿里云 ESA** | 国内节点的静态托管，上传目录即发布，自带 HTTPS 与二级域名 | 免费额度够用 | 需实名；绑定自定义域名要 ICP 备案，**用平台给的二级域名可免备案** |
| **C. GitHub Pages** | 建仓库上传后开启 Pages | 免费 | 域名 `*.github.io` 国内访问时快时慢；学术圈常用，但别指望稳定 |

> ⚠️ 两个常见坑
> - **对象存储（OSS / COS）不要直接当网站用**：默认域名访问 `.html` 会被强制下载而不是渲染，必须绑备案域名才行。
> - **不要用 http 地址**：主页是 https，嵌 http 会被浏览器当混合内容直接拦掉，页面一片空白。

拿到地址后，先用手机 4G（不连校园网）打开一次，确认外网能访问。

---

## 2. 路线 A：加一个「课题组」栏目做入口（推荐，约 20 分钟）

这是最稳、最不影响主页原有结构的方式。

### 2.1 建栏目

1. 登录 <https://teacher.yzu.edu.cn/> → 进入后台 → 顶部菜单 **栏目管理**；
2. 左侧树选中 **中文主页栏目管理**（要建一级栏目就选它，不要选二级栏目）；
3. 点 **新增**，填写：
   - 栏目名称：`课题组`
   - 在导航中显示：**是**
   - 资料来源类型：选「自定义栏目」（若无可选项，先建栏目再在内容管理里补内容）
4. 点 **发布**。
   > 「暂存」只在后台可见，前台不显示；一定要点「发布」。
5. 同样的操作，在 **英文主页栏目管理** 下再建一个，名称填 `Research Group`。

### 2.2 放内容

1. 顶部菜单 **内容管理** → 选中刚建的「课题组」栏目 → **新建**；
2. 标题填 `裴玮课题组`；
3. 正文编辑器切到 **源码 / HTML 模式**（工具栏右侧），把 `embed/01-入口卡片.html` 整段粘进去，改掉里面的 `https://lab.example.com` 为真实地址；
4. 切回可视化模式检查一下排版 → **保存 → 发布**。

效果：主页导航多出「课题组」，点进去是一张与网站风格一致的卡片，再点按钮跳转到独立站点。

---

## 3. 路线 B：整站内嵌进栏目页（需实测，约 30 分钟）

如果希望访客不离开主页就看到完整网站，用 iframe。

### 3.1 操作

同 2.1 建好栏目，然后在 2.2 的正文里改粘 `embed/02-iframe嵌入.html`，把 `src` 换成：

```
https://你的地址/?embed=1
```

`?embed=1` 是必须的：它会让网站隐藏自己的 logo、署名和页脚（否则和学校主页重复两遍），只保留栏目导航；hash 路由要写在它后面，例如 `/?embed=1#/publications`。

### 3.2 三个可能失败的点，以及各自的处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 粘贴保存后再打开，iframe 消失 | 编辑器做了安全过滤，白名单里没有 iframe | 退回路线 A |
| 页面能显示但高度只有 1500px，内部出现滚动条 | `<script>` 被过滤，自动撑高失效 | 把代码里 `height:1500px` 改成 1800～2200，或接受内部滚动 |
| 一片空白 | 地址是 http，或对方站点发了 `X-Frame-Options: DENY` | 换 https；自己部署的站点不会有这个响应头，可控 |

### 3.3 建议

- **桌面端值得嵌，移动端不建议**：主页模板的内容区宽度有限，手机上嵌进去会挤成一条，体验不如直接跳转。
- 若同一个栏目既要「嵌」又要「跳」，可以嵌首屏、下方放一个「在独立窗口中打开」的文字链接。

## 4. 路线 C：不建独立入口，把内容搬进主页现成栏目

不需要任何托管，但站点的设计感和自动聚合都会失去。适合作为「合规底线」的兜底方案。

| 课题组网站板块 | 主页系统对应栏目 | 位置 |
| --- | --- | --- |
| 首页（简介、指标） | 个人信息管理 → 个人简介 | 已存在，可直接扩写 |
| 成员介绍 | 学生信息 | 栏目管理 → 学生信息 |
| 研究方向 | 科学研究 → 研究领域 | 已存在 |
| 科研成果 · 论文 | 科学研究 → 论文成果 | 已存在，支持从学校数据中心带出 |
| 科研成果 · 项目 | 科学研究 → 科研项目 | 已存在 |
| 新闻动态 | 课题组动态 | 已存在 |
| 招生招聘 | 招生信息 | 已存在 |
| 联系方式 | 个人信息管理 → 联系方式 | 字段形式，非文章 |

> 论文成果如果是从业务系统（科研管理系统）自动带出的，标题前的勾选框是灰的，不能在主页里改；确需修正要走科研系统或联系对应管理员。

---

## 5. 选哪条？

- **只想让人看到这个网站** → 路线 A。20 分钟，风险最低。
- **希望它看起来像主页的一部分** → 路线 B，先在预览里试，能行就用。
- **学校要求所有内容必须在本平台上** → 路线 C 打底，同时用路线 A 挂一个「完整版」外链。

无论哪条，**第一步都是先拿到 https 地址**——没有地址，A 和 B 都做不了。

---

## 6. 后续维护

| 要改什么 | 改哪里 | 之后做什么 |
| --- | --- | --- |
| 论文、成员、项目、招生文案 | `assets/js/data.js` | 重新上传整个目录（或用下面的单文件版） |
| 界面文字、按钮 | `assets/js/app.js` 里的 `I18N` | 同上 |
| 配色、间距 | `assets/css/site.css` 顶部 `:root` | 同上 |
| 新闻 | 跑 `python scripts/fetch_news.py` | 重新上传 `data/news.json`，或重新打包 |

主页那边只维护**一个链接**，不用两套内容同步 —— 这是把网站独立出去最大的好处。

### 单文件版

```bash
python scripts/build_standalone.py
# 生成 dist/pei-lab-standalone.html（约 140 KB，CSS/JS/新闻数据全部内联）
```

用途：托管平台只允许传单个文件时、用邮件或 U 盘把网站发给别人看时、临时演示时。
双击即可打开，不需要服务器；此时新闻栏目读的是打包那一刻的数据。

---

## 7. 已经准备好、可直接用的文件

```
embed/01-入口卡片.html      路线 A 用，粘进富文本的源码模式
embed/02-iframe嵌入.html    路线 B 用，同上
dist/pei-lab-standalone.html 单文件整站，双击可看
scripts/build_standalone.py  重新打包单文件版
```

两段代码里的 `https://lab.example.com` 都要替换成真实地址再粘贴。
